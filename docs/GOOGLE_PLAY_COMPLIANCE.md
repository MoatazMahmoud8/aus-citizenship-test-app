# Google Play Compliance — Misleading Claims Policy

## Problem: Policy Violation — Misleading Claims

Google flagged the app for two reasons:

### 1. Government Affiliation
The app was perceived as potentially representing an official government entity because it provided government information without:
- A clear **disclaimer** stating the app is independent
- A **link to the original government source**

### 2. Promotional Language in Metadata
Using keywords like **"Guaranteed"** or **"Money Back"** in the **Short Description** is a violation. Google considers this "store status" or "promotional" language, which is strictly **prohibited in the 80-character summary**.

---

## Resolution: Compliance-First Strategy

### Full Description Updates
1. **Bold Disclaimer at the top** — Clearly states the app is an independent study tool by **JSM GLOBAL PTY LTD** and is **not affiliated with the Australian Government**
2. **Official Source Link** — Direct, functional URL to the Department of Home Affairs ([Our Common Bond .gov link](https://immi.homeaffairs.gov.au/citizenship/test-and-interview/our-common-bond)) as required by policy
3. **Moved the Guarantee** — Relocated "Pass Guarantee" and "Refund" details to the Full Description body, where it is safer and allowed

### Short Description Updates
- **Rewrote to be purely descriptive**: `Master the 2026 AU Citizenship Test with 5000+ Practice Questions & Mock Exams.`
- Removed all promotional/guarantee language from the 80-character summary
- This satisfies the "store status" policy

### Visual Assets
- Replaced old screenshots with professional, high-conversion visuals
- Focus on the "Golden Shield" (Pass Guarantee) and question bank
- Ensures images sell the benefits even when the short text is formal

---

## Rules to Follow (Prevent Future Violations)

### Short Description (80 chars max)
- **DO**: Describe the app's function factually
- **DON'T**: Use "Guaranteed", "Money Back", "Free", "Best", "Official", "#1"
- **DON'T**: Reference awards, rankings, or performance claims

### Full Description
- **MUST** include a disclaimer if providing government/official information
- **MUST** link to the original government source
- **CAN** include guarantee/refund details here (not in short description)
- **CAN** include promotional language (within reason)

### General Metadata
- Never imply government affiliation or endorsement
- Always attribute content to its original source
- Keep promotional claims out of the short description
- Review Google's [Misleading Claims Policy](https://support.google.com/googleplay/android-developer/answer/9898842) before each submission

# Changelog - ACE Aus Citizenship Test App

All notable changes to this project will be documented in this file.

## [1.0.0] - April 1, 2026

### Added
- Launched ACE Aus Citizenship Test App
- 150 verified citizenship test questions
- Beautiful landing page with feature showcase
- Privacy policy page at jsmglobal.xyz/privacy.html
- Android app on Google Play Store
- Monthly update announcements on homepage
- Support email: support@jsmglobal.xyz

### Features
- Complete Study Material: 150 comprehensive citizenship questions
- Practice Questions: Full question bank covering all test topics
- Progress Tracking: Monitor your learning progress
- Exam Format: Questions presented in official test format
- Accessible: Works on Android devices
- iOS Coming Soon

# Asset Placeholders

Before publishing, replace these placeholder files with your actual app assets:

## Required Files

| File | Size | Purpose |
|------|------|---------|
| `icon.png` | 1024×1024px | App icon (both platforms) |
| `adaptive-icon.png` | 1024×1024px | Android adaptive icon foreground |
| `splash.png` | 1284×2778px | Splash/loading screen |
| `favicon.png` | 48×48px | Web favicon |

## Design Recommendations

- Use the Australian colour scheme: Blue (#002B7F), Gold (#FFD700), Green (#00843D)
- Include the Southern Cross or Australian imagery
- Keep the icon simple and recognisable at small sizes
- The splash screen should feature the app name on the blue background

## Free Design Tools

- [Canva](https://canva.com) — Easy design tool
- [Figma](https://figma.com) — Professional design
- [Icon Kitchen](https://icon.kitchen) — Generate platform-specific icons
